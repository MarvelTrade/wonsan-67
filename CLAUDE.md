# ВОНСАН-67 — прототип tower defense (серия 2)

## Что это
Браузерная 2D-игра, вид сверху, горизонтальный экран. 1967 год, выдуманный город на побережье (название —
отсылка к году). Из фиолетовых врат лезут гоблины и копейщики и идут по дороге к убежищу. Игрок водит
вертолёт одним пальцем: пулемёт стреляет сам, вертолёт забирает людей и везёт к грузовику. **Спасённые
люди — единственный ресурс**: на них строятся пушки (пулемётные гнёзда) и колючая проволока в местах
постройки вдоль дороги.

Цель прототипа — проверить, работает ли связка «спасаешь людей → строишь» и возникает ли сам, без
отдельного кода, подвох **«проволока под пушкой → копейщики разбивают пушку»**.

Основа — GORKY-67 (`MarvelTrade/gorky-67`): стек, управление вертолётом и его числа. Репозиторий
GORKY-67 не менять. Копия для справки на ПК — `Documents/gorky-67-ref`.

## Обязательные правила
- **Мир вымышленный.** Без реальных марок, событий, организаций и людей. Институт героев — выдуманный.
- **Все числа баланса и раскладки — только в `src/config.js`.** Меняя баланс, оставлять комментарий,
  какой замер к этому привёл.
- **Без новых механик**, пока автор не решит после плейтеста. Сейчас есть ровно: один уровень, 3 волны,
  пушка, проволока, гоблин, копейщик, люди, вертолёт.
- **GitHub — пушит автор сам.** Агент только коммитит локально и даёт команду для пуша.
- Делать по шагу, после рабочего шага — `npm run build`, проверка консоли, коммит.

## Стек
Phaser 4, JavaScript, Vite. Графика — примитивы Phaser.

## Структура
```
src/config.js          — все числа: карта, вертолёт, люди, постройки, враги, волны, бот, отрисовка
src/sim/World.js       — вся логика забега без Phaser (шаг фиксированный, SIM.dt)
src/sim/bot.js         — бот: водит вертолёт и строит по плану
src/sim/path.js        — дорога-ломаная и генератор случайных чисел с seed
src/scenes/GameScene.js — отрисовка, ввод, HUD, экран итогов
src/texts.js           — все тексты интерфейса
src/telemetry.js       — запись итогов в localStorage['wonsan67.runs']
scripts/sim.mjs        — прогон бота в Node
docs/art-style.md      — стиль рисовки манхвы
```

## Правила игры (как сейчас устроено)
- Дорога от врат (справа) к убежищу (слева). Прорвавшийся гоблин −1 убежищу, копейщик −2. Убежище 0 — поражение.
- 3 волны; перед первой 30 с, между волнами 25 с. Пережил третью — победа.
- Люди появляются в точках карты и ждут ограниченное время. Вертолёт берёт до 3, сдаёт у грузовика.
- Нажатие по кругу места — меню: пушка или проволока. Проволока ложится на дорогу в ближайшей к месту
  точке, замедляет всех в ней и понемногу рвётся.
- Копейщик бьёт на ходу любую пушку, до которой достаёт копьё. Подвох не запрограммирован отдельно:
  проволока под пушкой держит копейщиков в зоне удара дольше, и пушка гибнет.

## Замеры
- Браузер: `?bot=2t1w&speed=4` — бот с 2 пушками и 1 проволокой; `?bot=0t0w` — без построек;
  `?bot=trap` — нарочно проволока под пушкой; `&seed=N` — повторить забег; `&runs=N` — N забегов подряд.
- Node: `npm run sim` или `node scripts/sim.mjs 0t0w 2t1w trap --runs 40`.
- Итоги каждого забега (и бота, и человека) — `localStorage['wonsan67.runs']`: результат, волна, спасено,
  пропало, потрачено на пушки и проволоку, пушек сломано и кем, проволок порвано, убито, длительность.
- Телефон: `npm run host`, адрес вида `http://192.168.x.x:5173/` (Windows может спросить про брандмауэр
  для Node — разрешить в частной сети).
