# «Вонсан-67» — план разработки для Claude Code

Цель: хорошая игра для Яндекс Игр (телефон, браузер), в которой Phaser 4 выжат по максимуму: свет, фильтры, частицы, GPU-слои — без потери 60 FPS на среднем телефоне.

Принцип плана: **каждая фаза заканчивается проверкой**. Следующая фаза не начинается, пока не выполнено условие перехода. Красота поверх неинтересной игры — потерянное время.

---

## Правила работы (добавить в CLAUDE.md)

1. Одна фаза — одна или несколько сессий. В начале сессии прочитать этот план, CLAUDE.md и навыки в `.claude/skills/`.
2. Каждый шаг — отдельный коммит с понятным сообщением. Push делаю я.
3. Все числа баланса — только в `src/config.js`. Все числа графики (яркость, радиусы свечения, количество частиц) — в `src/config.visual.js`.
4. После любой правки баланса — прогон бота (`?bot=…&speed=4`) и таблица результатов до/после.
5. После любой визуальной правки — скриншоты в двух размерах: десктоп 1280×720 и телефон 812×375 (горизонтально). Проверить: текст не перекрывает людей, дома и героев.
6. Не добавлять механики, которых нет в этом плане. Идея вне плана — записать в `IDEAS.md` и продолжить работу.
7. Мир вымышленный: без реальных стран, флагов, гербов, лидеров, моделей техники.

## Подготовка: официальные навыки Phaser 4

Установить в проект официальные навыки Phaser для Claude Code:

```
npx skills add phaserjs/phaser --skill v4-new-features --agent claude-code
npx skills add phaserjs/phaser --skill filters-and-postfx --agent claude-code
npx skills add phaserjs/phaser --skill v3-to-v4-migration --agent claude-code
```

Если какой-то навык не найдётся под этим именем — посмотреть список навыков в репозитории phaserjs/phaser и поставить ближайший. Перед работой с фильтрами, светом и GPU-слоями — читать их, а не писать по памяти: API Phaser 4 сильно отличается от Phaser 3 (FX → Filters, Pipelines → RenderNodes, `setPipeline('Light2D')` → `setLighting(true)`).

## Фаза 0. Остановка и плейтест

Сейчас в прототипе уже есть элитные враги, обложка тома и оглавление глав, а плейтеста ещё не было. Сначала проверяем ядро.

- [ ] Довести текущую задачу (оглавление глав), закоммитить, остальное не начинать.
- [ ] **Титры и радиореплики — только внизу экрана.** Нижняя полоса высотой ~18% экрана, полупрозрачная подложка. Ничто текстовое не появляется в зоне, где ходят люди, стоят дома и идёт бой. Портрет говорящего — слева в этой полосе.
- [ ] Режим `?bot=0t0w` (без построек) для проверки, что без обороны уровень проигрывается.
- [ ] FPS-счётчик по `?debug=1`.
- [ ] Плейтест: я + 5 человек, по 3 забега, на телефонах.

**Условие перехода:** большинство само нажимает «Ещё раз» и доходит до волны 3. Нет → неделя на числа в config.js и повторный тест. Опять нет → стоп проекта.

## Фаза 1. Читаемость и управление

Игрок должен за секунду понимать, что происходит.

- [ ] Безопасные зоны: верх — ресурс и волна, низ — титры, центр — только игра. Учесть вырез камеры (safe-area) на телефонах.
- [ ] Слоты и отметки под укрепления — не меньше 48 px, подсветка доступного по цене.
- [ ] Радиус пушки показывается при постройке и при тапе по ней.
- [ ] Цифры урона — маленькие, всплывают и гаснут за 0,5 с. Отключаемые.
- [ ] Индикатор у края экрана, если человек или враг за кадром.
- [ ] Вертолёт: тень на земле (смещённая, полупрозрачная) — сразу видно высоту и положение.
- [ ] Подсказка первого запуска: одна стрелка «веди пальцем» и одна «тапни по кругу». Без текстовых стен.

**Проверка:** новый человек без объяснений строит пушку и подбирает человека в первую минуту.

## Фаза 2. «Сочность» (game feel)

Самый дешёвый способ сделать игру приятной. Делается до графики.

- [ ] Hit-stop: при убийстве элиты — пауза 40–60 мс.
- [ ] Камера: лёгкая тряска от взрывов мин и миномёта, вспышка при открытии врат, плавный зум на боссе (`camera.shake`, `camera.flash`, `camera.zoomTo`).
- [ ] Попадание: враг мигает белым через tint-режим FILL на 1–2 кадра.
- [ ] Выстрелы: вспышка у ствола, трассеры, гильзы у пулемётного гнезда.
- [ ] Смерть гоблина: распад на частицы, зелёные брызги без крови.
- [ ] Постройка пушки: «проявление» — силуэт светится, собирается из частиц (это сила сержанта, должно выглядеть как магия).
- [ ] Подбор человека: частица летит к счётчику ресурса, счётчик подпрыгивает.
- [ ] Твины на всём интерфейсе: кнопки пружинят, панели выезжают, а не появляются.

**Проверка:** видео 30 секунд игры смотрится интереснее, чем до фазы. Сравнить записи до/после.

## Фаза 3. Графика Phaser 4 — максимум движка

Делать по слоям, после каждого слоя — замер FPS на телефоне. Каждый эффект выключается настройкой «Качество: высокое / низкое».

### 3.1 Небо и время суток
- [ ] Небо — объект **Gradient** с несколькими полосами цвета, а не картинка.
- [ ] Цветокоррекция сцены фильтром **GradientMap** или **ColorMatrix** на камере: у каждой серии свой час — рассвет, день, закат, ночь. Один параметр в конфиге уровня.
- [ ] Виньетка собрана из фильтров (в Phaser 4 готовой Vignette нет).

### 3.2 Врата — главный визуальный крючок
- [ ] Тело врат — объект **Noise** (simplex), анимируемый через `noiseFlow`: живая клубящаяся поверхность.
- [ ] Свечение края — фильтр **Glow**.
- [ ] Искажение мира вокруг врат: **CaptureFrame** захватывает картинку за вратами, фильтр **Displacement** её плавит.
- [ ] Цвет врат зависит от ранга: E — фиолетовый, D — синий, C — красный и т. д.

### 3.3 Свет и ночь
- [ ] Освещение через `setLighting(true)` на земле, домах, пушках, врагах.
- [ ] Нормал-карты для земли и скал — из объекта **Noise** с `noiseNormalMap: true`, рисовать не нужно.
- [ ] Источники света: врата (фиолетовый, пульсирует), вспышки выстрелов, взрывы, фары грузовиков, прожектор вертолёта.
- [ ] Ночная серия (по плану — серия 7): сцена тёмная, видно только освещённое. Это механика, а не декор: враги в темноте видны хуже.

### 3.4 Земля и окружение
- [ ] Статичный декор (трава, камни, кусты, столбы, обломки) — **SpriteGPULayer**: тысячи объектов почти бесплатно.
- [ ] Карта уровня — тайлы на **TilemapGPULayer**.
- [ ] Море — тайловый спрайт + фильтр Displacement, блики.
- [ ] Глубина: дальний план (горы, город) размыт фильтром Blur, ближний — резкий.

### 3.5 Персонажи и враги
- [ ] Тени от юнитов (фильтр Shadow или спрайт-тень).
- [ ] Элита — светящийся контур (Glow) и цветной tint-режим ADD.
- [ ] Босс — отдельная полоска здоровья внизу над титрами, своё свечение, фаза ярости меняет цвет.

### 3.6 Переходы
- [ ] Перелистывание страницы манхвы (уже есть) — использовать везде: меню → глава → уровень → итоги.
- [ ] Переход «вспышка врат» при начале волны.

**Бюджет производительности:** 60 FPS на телефоне уровня 3–4-летнего среднего Android. Если не держит — сначала выключать фильтры уровня external (экранные, дорогие), потом частицы. Замер обязателен на реальном телефоне, не только в эмуляторе.

**Проверка:** скриншот уровня можно ставить обложкой в каталог Яндекс Игр без стыда.

## Фаза 4. Контент сезона 1 (серии 1–3)

Строго по концепции, ничего сверх.

- [ ] Серия 1 «Нулевая волна»: только вертолёт и спасение людей.
- [ ] Серия 2 «Здесь нужна пушка»: пулемётное гнездо, колючая проволока, гоблины и копейщики (ранг E).
- [ ] Серия 3 «Приоритет — архив»: окоп, гоблин-шаман, выбор «архив или колонна», мини-босс гоблин-вождь (ранг D).
- [ ] Манхва-вставки: 3–5 кадров до и после каждой серии, листаются тапом, кнопка «Пропустить».
- [ ] Радиоправило: подвох объясняется репликой **после** того, как случился, а не до.
- [ ] Медик: пассивное лечение вертолёта и пушек рядом.
- [ ] 3 звезды за серию: победа, ни один грузовик не повреждён, архив спасён / все люди спасены.

**Проверка:** плейтест на 5–10 людях. Доходят ли до конца серии 3. Сколько пропускают манхву (замер).

## Фаза 5. Звук

- [ ] Звуки: пулемёт, миномёт, лопасти (громкость от скорости), гоблины, открытие врат, подбор человека.
- [ ] Радио: шум и щелчки под каждую реплику.
- [ ] Музыка: спокойная в паузе, напряжённая в волне, плавный переход между ними.
- [ ] Звук глушится при сворачивании вкладки и во время рекламы (требование Яндекс Игр).
- [ ] Кнопка «без звука» сохраняется.

## Фаза 7. Яндекс Игры

- [ ] Подключить SDK Яндекс Игр, вызвать готовность игры после загрузки.
- [ ] Реклама: межстраничная — между сериями, не чаще ограничений платформы. С вознаграждением — «+3 человека» перед волной или повтор серии с места поражения.
- [ ] Облачные сохранения через SDK.
- [ ] Вес сборки: сжать текстуры, атласы спрайтов, проверить время загрузки на мобильном интернете.
- [ ] Обложки и скриншоты для каталога — 2–3 варианта для A/B.
- [ ] Пройти требования модерации: язык, пауза при сворачивании, отсутствие внешних ссылок.
